## 2026-09-27 验证号：用真实手机号 + 人工发布，不用虚拟号 + 云端浏览器
- 决定（Claude 建议，待 Chris 确认）：验证号用 Chris 本人的真实加拿大手机号注册（可另办一张预付费 SIM 卡），在自己手机上发布；Claude 负责写稿，Jev 负责打分；数据由人工从创作者后台导出。
- 理由：虚拟号（VoIP）注册 + 云端机房 IP + 无头浏览器 + 每次都是新设备，是典型的风控高危特征 → 账号可能被限流或封号，实验测到的会是风控结果而不是内容质量；同时违反平台规则，也有实名制问题；另外当前网络策略拦截了 xiaohongshu.com。
- 放弃：Twilio 号码注册 + 云端浏览器登录与自动化操作。
