# 踩坑清单：儿童历史动画（云端 + 本地）

> 用途：① 出片前逐条对照；② 每个坑都要变成自动检查，全自动出片时不再犯。
> 来源：Chris 在本地会话里的原话、`memory/log/`、`memory/DECISIONS.md`、git 提交记录、`docs/画面改版-纸片马里奥风格-给云端.md`。云端对话本地看不到，只能从云端写进仓库的记录里整理；云端如有漏记，补在对应分类下。
> 建立：2026-09-29（本地）。

## 更新规则（云端和本地都要遵守）
1. **Chris 每次要求修改，先记再改**：在对应分类末尾加一行。「现象」尽量用 Chris 的原话，写上日期，标明是云端还是本地。
2. **修好后补齐**：写清根因、规则 / 修法、自动检查。能写成脚本检查的一定要写。暂时写不成的标 ❌，并加到最后的「待补的自动检查」。
3. **同一个坑再犯**：不新开一行。在原行「自动检查」一栏后面写「再犯 MM-DD」，并说明检查为什么没拦住，然后把检查补上。
4. **出片前**：按「交付前检查清单」跑完，并在 `memory/log/` 里写一句结论。
5. 编号一经分配就不改，以后用编号引用（比如「B3 再犯」）。

图例：✅ 有脚本自动查，⚠️ 靠人看（容易漏），❌ 还没有检查。
