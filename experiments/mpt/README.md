# MoneyPrinterTurbo 对比实验（2026-09-28）

Chris 的要求：用我们**已经生成好的图片素材**，按 MoneyPrinterTurbo（MPT）的 skill 从头做一条徙木立信的视频（不是在原版上优化，是重做），对比有这个 skill 和没有的区别。

- skill：https://raw.githubusercontent.com/harry0703/MoneyPrinterTurbo/main/docs/skill/SKILL.md（v1.3.2；helper 是同目录的 `mpt_agent.py`，已通读：只做下载项目、`uv sync`、检查配置、调用 `cli.py`，不会打印密钥）
- **有效的一次：`bash experiments/mpt/run_images.sh`** → `output/mpt_images_2026-09-28.mp4`（26.7 秒，全程 7 分钟，全自动）
  - 素材：15 张我们生成的图（人物、道具、场景），`prepare_images.py` 只做两件事：放大到 MPT 能接受的尺寸（它会丢掉短边小于 480 像素的图），以及给透明底垫一层米色；顺序按故事排
  - 故事要求：`prompt_images.txt`（同一个故事、同样的史实要求）
  - 其余用 skill 的默认值（中文 9:16、Edge TTS 晓晓、字幕、随机背景音乐）；改了三个默认值：本地素材、按顺序拼接、每张图最长 2 秒
  - 大模型：`claude_code`（调用本机已登录的 claude 命令行写文案，工具全部关闭）
- ~~第一次（`run.sh`，`output/wrong_clips_*`）~~：我理解错了，把我们渲染好的动画切段喂给了 MPT，等于只给原版配了音，**对比无效**，只留作记录

## 环境坑
- GitHub 的 zip 下载被拦 → 用 git 克隆官方仓库
- 云端只能走代理：Edge TTS 走 wss://，aiohttp 只从 WSS_PROXY 读代理 → 脚本里设置 WSS_PROXY=HTTPS_PROXY（MPT 源码没改）

## 对比（有 skill = MPT 图片版；没 skill = 我们的纸偶动画流水线）
| | MPT 图片版 | 我们的流水线 |
|---|---|---|
| 速度 | 7 分钟，全自动 | 渲染 100 秒，但动作和场景前后改了 5 轮 |
| 画面 | 一张图一张图轮流放，每张 1.8 秒，加一点缓慢放大；人物不动、不在场景里 | 人物在场景里走、搬、接，有动作 |
| 画面和旁白 | 不对齐：MPT 用本地素材时不看内容，只按时长平均分；旁白说「加到五十金」时画面是农夫，「扛到北门」时画面是大婶，大概错开 3–4 秒 | 按帧对齐 |
| 配音、字幕、背景音乐 | 全自动都有 | 还没做（第 4 轮），音乐是代码合成的，难听 |
| 文案 | 每次都不一样；这次又把「搬」写成「扛」 | 剧本定稿，逐句核对过两次史料 |
| 字幕 | 浅色字压在米色底上，看不清 | 纸片字幕卡 |
| 素材本身的问题 | 「小伙领赏」那张图捧的是方孔铜钱（秦国那时没有），旁白却说五十金 | 已经改成金块 |

结论：MPT 适合「一堆图 + 一个题目 → 很快出一条配好音、字幕、音乐的成片」；它不理解画面内容，讲故事时画面和旁白对不上。可以借用它的配音、字幕、配乐环节，编排还得用我们自己的。
