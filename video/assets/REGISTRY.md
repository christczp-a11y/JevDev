# 素材登记表（`video/assets/`）

> 建立：2026-09-29（tj01 第 0 步第 3 项）。这张表是第 3 步画素材、第 5 步分场、第 6 步朝向检查（第 0 步第 22 项）的数据来源。
> 改动这张表以后，跑 `python video/registry_check.py`（退出码 0 才算登记齐全）；测试在 `video/tests/registry/`，一条命令 `bash video/tests/registry/run_all.sh`。

## 用法（先读）

1. **新素材画完、拆完图，先在这里登记，再进场景。** `chars/`、`props/`、`rig/`、`sets/`、`brand/` 下每张 png 占一行，共 8 列：路径、属于谁、**原图朝向**、像素尺寸、图里有没有带别的角色、状态、备注、范围。尺寸要和实际图片一致（图重新导出过就更新）。
2. **新角色的前缀不许和第一节里任何一行重名**（旧版的、停用的前缀也算）；也不许是它们的前缀，或者以它们为前缀（有了 `sy_`，就不能再用 `sy_a_`）。新角色一行：定稿前缀、首次出现的集、朝代服饰要点、`PX`、状态；同时把 `PX` 写进本集配置 `video/episodes/<集>.py`（新前缀不登记就用默认比例 0.42）。
3. **状态是三选一**：
   - **定稿**：这个角色（或这套道具、这套纸偶部件）的**设计**已定稿，同一套姿势图都算。后面括号里写待修的地方（司马光的领口就是）。在试做集 v2 里用没用过，写在备注里，不影响状态；
   - **未定稿**：设计还没定：被换掉的早期版本（`farmer_`、`youth_excited`）、从没进过成片的角色（`window_head`）、试做集布景、账号宣传图里的人物和备选头像。场景里用了它，`registry_check.py` 打印警告，用之前先问主会话；账号宣传图里的人物只能用在宣传图上；
   - **停用**：不许用。第三节列全了。场景 JSON 里出现停用的素材，`registry_check.py <场景 JSON 或目录>` 退出码就是 1。
4. **范围（最后一列）**：
   - `系列`：每集都能用（司马光）；
   - `试做集`：只属于试做集，**新集不许用**（T19、S7）；
   - `宣传图`：不进视频；
   - 某一集新画的素材写集名（`tj01`）。哪个角色以后成了系列角色（比如韩、赵、魏），把它的范围改成 `系列`。
   - 新集（场景 JSON 所在目录不是 `ep01`、`ep01v2`）的场景里用了 `试做集` 范围的素材，或者 `qin_gate`、`classroom` 布景，`registry_check.py` 报错、退出码 1。集名取场景 JSON 所在的目录名（`video/scenes/<集>/shotN.json`），不在这种目录里的用 `--ep 集名` 指定。
5. **朝向 = 原图朝向**，只写 `左`、`右`、`正面` 三个字之一，逐张看图定的，不看文件名猜（T13、T17）：
   - 看脸和视线、脚尖、手势和衣襟的前后，综合判断哪一侧；3/4 侧面记它朝的那一侧（备注里写「3/4」）；
   - **一张图里有几个人时，每个人都按脸、脚尖、衣襟前后综合判断，备注逐人写**；
   - 只有脸和视线都正对镜头、没有指向的，才记 `正面`；
   - 物件没有方向的（课桌、书、木杆），也记 `正面`；有方向的（乌鸦的嘴、折纸鸟的头、旗面）照实记；
   - 纸偶部件（`rig/`）整个纸偶按面朝右装配，facing < 0 时整体镜像，单个部件的朝向只是备忘。
   - 场景 JSON 里 actor 的 `native` 就是这一列：原图朝右写 1，朝左写 -1，`正面` 写 1（`engine.html`：`native === -1` 时镜像）。`registry_check.py <场景>` 会按这一列逐个 actor 自动对账，不一致的列出来并退出 1；朝向检查（第 0 步第 22 项）也按这一列算「角色有没有面向主体或说话的人」。
6. **T19：tj01 起，布景、道具、人物全部按竖屏 2.5D 重新画。试做集的布景（`sets/` 下全部）只作参考，不许拿来凑。** 每层图的尺寸要够镜头推拉：屏幕上显示的大小 ÷ 原图大小 ≤ 1.3（T14、T19）。现在的姿势图只有 500 像素左右高，拍特写要另画高清图。
7. **停用的文件先不挪、不删**（`render.py` 每场都会预载 `coin.png`，`build_ep01.py` 也还在用旧前缀）。只要场景里不引用，就不会画出来。
8. 朝代对不对，看 PITFALLS S4（钱币和金子）、S5（戏曲符号）、S6（宋代圆领）；每集简报里的「朝代器物服饰清单」是逐张核对的依据。
9. 判断朝向用的联系表（每张 300 像素高，带文件名）在 `video/out/tj01/registry_sheets/`，不进 git，可以重新生成。
