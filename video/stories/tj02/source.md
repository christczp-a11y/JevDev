## 一、通鉴怎么排的
威烈王二十三年（前 403）那条分四部分，魏文侯在第 ③ 部分的后半（tj01 第一节已列前三条）：
- 前半是豫让、三家世系，最后一句是 「魏斯者，桓子之孫也」（鉴1）；
- 接着一整段合着写魏文侯的好几件事，**没有年份**：尊师 → 虞人之约 → 韩赵借兵 → 乐羊伐中山 → 任座 → 田子方 → 问相（李克、翟璜）→ 吴起归魏。本集的故事就是其中的第二件；
- 之后才是第 ④ 部分（燕国）。
- 所以这是 “通鉴把魏文侯的事合在册命之后追叙”，不是 “安王二十六年的追叙”。虞人之约具体是哪一年、哪一天，通鉴没写【未核实，不进剧本】。
- 这一段**没有 “臣光曰”**（该年两段臣光曰是礼和才德，在它前面，见 tj01）。

### 通鉴与《战国策》的虞人那段，逐句对照
《战国策·魏策一》有一段独立的 “文侯与虞人期猎”（网7）：
| 句子 | 通鉴（鉴1） | 战国策（网7） | 只在哪 |
|---|---|---|---|
| 开头 | 「文侯與群臣飲酒，樂，而天雨，命駕將適野」（鉴1） | “文侯與虞人期獵。是日，飲酒樂，天雨。文侯將出” | “与虞人期猎” “是日” 只在战国策 |
| 左右的话 | 「今日飲酒樂，天又雨，君將安之」（鉴1；胡1） | “今日飲酒樂，天又雨，公將焉之” | 通鉴称 “君”、用 “安之”；战国策称 “公”、用 “焉之” |
| 文侯的话 | 「吾與虞人期獵，雖樂，豈可無一會期哉」（鉴1；胡1） | “吾與虞人期獵，雖樂，豈可不一會期哉” | 通鉴是 “無”，战国策是 “不” |
| 去了 | 「乃往，身自罷之」（鉴1；胡1） | “乃往，身自罷之” | 两书一样 |
| 结论 | 没有这一句 | “魏於是乎始強” | **只在战国策，通鉴没有** |

通鉴把 “始大” 放在借兵那件事后面（第二节第 9 条）。战国策是把 “始强” 放在虞人之约后面，两书的因果不同。

## 三、“臣光曰”和点题的话
**通鉴这一段没有臣光曰**，司马光只是记下了这件事。但他在卷二写商鞅徙木立信时，**自己提到过虞人之约**（鉴2，显王十年，前 359）：
- 「夫信者，人君之大寶也」（鉴2）：信用是最大的宝贝。
- 「國保於民，民保於信」（鉴2）：国家靠民众保住，民众靠 “信” 保住。
- 「非信無以使民，非民無以守國」（鉴2）。
- 举例：「魏文侯不棄虞人之期」（鉴2）（与齐桓公、晋文公、秦孝公并列四件守信的事）。
- 「猶且不敢忘信以畜其民」（鉴2）：那个时代天下都讲欺诈和武力，这几位还是不敢丢掉信用。

**点题推荐**：「吾與虞人期獵，雖樂，豈可無一會期哉」（鉴1；胡1）。短版：「雖樂，豈可無一會期哉」（鉴1；胡1）。
- 白话：“我跟管山林的人约好了去打猎。这里喝得再开心，怎么能不去见他一面、守住约定呢？”（“一會期” 是去赴一次约会，不是 “一会儿”。）
- 备选：「魏文侯不棄虞人之期」（鉴2）。
- 台词注意：卷二那段臣光曰用的是 “君主对百姓守信” 的角度。按 10-01 的规则（比喻不分身份高低），片子里改成平等的说法：人和人之间靠信用，孩子之间的约定也一样。不要出现 “大人物对小人物” 的对比。

## 四、人物
| 人物 | 做了什么 | 画的时候注意 |
|---|---|---|
| 魏文侯 | 魏桓子的孙子（鉴1；史44），前 403 年受封为 “侯”；尊师；守约；不借兵给韩、赵；用乐羊、吴起；任用李克（见第二节） | 称 “侯”，**不是王**：不戴王冠，不画龙袍。通鉴没写外貌、年龄。沿用 tj01 魏家的橙黄色；交领右衽。**车上是站着的**（「古者立乘」（胡1））。他旁边的人称他 “君”（鉴1）或 “公”（策魏一）。“主公” 通鉴里没有 |
| 虞人 | 管山林的官。鲍本：“虞人，掌山澤之官”；吴师道引《孟子》注：“孟子注，守苑囿之吏”（网7）；胡注：「《周禮》有山虞、澤虞，以掌山澤」（胡1），虞的意思是「虞，度也」（胡1） | **通鉴没写他的名字、年纪、相貌、住处和穿着**，全部是画面创作，不进台词。**不要叫他 “小人物” “基层小官” “看林人里最低的”**（官阶没有出处，也违反 10-01 的规则）。台词称 “管山林的人” 或 “虞人” |
| 左右、群臣 | 一起喝酒的人；左右是身边的近臣，劝文侯别出门（鉴1） | 不当反派，不丑化；脸上是着急、关心 |
| 吴起 | 卫国人，听说文侯贤，往魏国去（「聞魏文侯賢，乃往歸之」（鉴1；胡1））；文侯用他为将，「擊秦，拔五城」（鉴1）；翟璜说他是西河守（第二节第 11 条） | 下集主角。画成会带兵的将军，**不画战场、血、伤**。他从前在鲁国杀妻、母死不奔丧，**整段跳过**，台词里不暗示。胡注说他守西河，秦兵不敢东来：「魏初使吳起守之，秦兵不敢東向」（胡1） |
| 乐羊 | 文侯派他去伐中山，打下后封给文侯的儿子（鉴1）；翟璜说他是自己推荐的（鉴1） | 只讲 “后来立了功”，不画战场。《战国策》里他的 “羹” 的故事不是通鉴的，整段不用（见第六节） |
| 李克 | 文侯问相，他讲 “看人五件事”（第二节第 12 条）；翟璜说他是自己推荐的：「臣進先生」（鉴1；胡1） | **写 “李克”，不写 “李悝”**（第七节）。画成温和的先生，穿交领 |
| 西门豹 | 翟璜推荐他去管邺这个地方：「君內以鄴為憂，臣進西門豹」（鉴1）；《史记》：「任西門豹守鄴，而河内稱治」（史44） | 通鉴只有这一句。“河伯娶妇” 的故事在《史记·滑稽列传》，整段跳过（第六节）。不要往他手里放别的东西 |
| 魏武侯 | 名 “擊”；文侯的太子，前 387 年即位（鉴1）；下集 “浮西河” | 比文侯年轻；**称 “侯”，不是王**；通鉴没写外貌 |
| 翟璜 | 文侯问相时，列出自己推荐过的人（鉴1） | 本集可以不出场，只在背景里提到 |

以上四人（吴起、乐羊、李克、西门豹）：**通鉴明写 “往歸” 的只有吴起**。乐羊、李克、西门豹是 “翟璜推荐”，他们原来是哪国人通鉴没写【未核实，不进剧本】。台词里说 “都在魏国帮文侯做事” 最稳，说 “都来到魏国” 只有吴起有出处。

## 七、常见误传（剧本逐条核对）
1. **“魏于是乎始强” 不是通鉴的话**，是《战国策·魏策一》的话（网7）。通鉴是「魏由是始大於三晉」（鉴1）（胡刻本作「魏於是始大於三晉」（胡1）），而且说的是韩、赵借兵那件事。
2. **两本的字不一样**：战国策是 “公将焉之”“岂可不一会期哉”；通鉴是「君將安之」（鉴1；胡1）、「豈可無一會期哉」（鉴1；胡1）（对照表见第二节）。红线 #1 改用的 “虽乐，岂可无一会期哉” 是通鉴的写法，没问题。
3. **出处纠正**：不是 “周安王二十六年追叙”，是威烈王二十三年（前 403）那条之下（见开头）。
4. **魏文侯、魏武侯是 “侯”，不是 “王”**。前 403 年周王册命是 “为诸侯”（「初命晉大夫魏斯、趙籍、韓虔為諸侯」（鉴1））。魏称王在前 334 年的徐州会盟：「齊王、魏王會于徐州以相王」（鉴2）；《史记》写在襄王元年：「襄王元年，與諸侯會徐州，相王也」（史44）。两书差一代，台词里不点名。
5. **李克和李悝**：通鉴写 “李克”（鉴1），《史记·魏世家》也写 “李克”（史44）。“李悝”（变法、《法经》）是别处的写法，是不是同一个人，我没能在线核对，古今也有争论【未核实，不进剧本】。**片子一律写 “李克”**，不要把 “尽地力”“法经” 这类说法放到李克头上（通鉴里没有）。
6. **“魏地盘最小、最弱” 没有出处。** 通鉴、史记都没比较过魏、赵、韩的地盘大小。
7. **“四面都是邻居、地势平、险阻少” 的出处是游说词，不是描述文侯时期。** 《战国策》里张仪对魏王说：“魏地方不至千里，卒不過三十萬人”，“諸侯四通，條達輻湊，無有名山大川之阻”（网7），这是百年后的魏国。下集魏武侯正好夸 “山河之固”（第九节）。
   “魏家夹在正中间” 这半句没有出处，也和 tj01 地图对不上（安邑在最南，韩的平阳才在中间）。能查到的邻居关系是：西边是秦（吴起守西河，秦兵不敢东来：「魏初使吳起守之，秦兵不敢東向」（胡1））；旁边是韩、赵（借兵那一段，鉴1）。建议台词改成 “魏家身边的邻居可不少”。
8. **“称霸”“得天下” 不是通鉴的话。** 通鉴只说 「諸侯莫能與之爭」（鉴1）。“称霸” 是春秋五霸的说法。
9. **“雷雨、暴风雨、深山、茅草棚、纯金酒杯、日历牌、下巴掉下来”** 都是 Gemini 剧本加的，通鉴没有（见第五、六节）。
10. **“身自罷之” 不是去打猎，是去取消**：胡注：「身往告之，以雨而罷獵也」（胡1）。这是胡三省一家的解释。
11. **因果别搞混**：通鉴写 「四方賢士多歸之」（鉴1；胡1），**排在虞人之约前面**，原因是 “以卜子夏、田子方為師，每過段干木之廬必式”。“守约所以人才来” 是剧本的推断，不是通鉴的话。说 “魏国人才越来越多” 没问题，别说 “因为这场雨”。
12. **“后来吴起、乐羊、李克、西门豹都来了”**：通鉴把这些事排在虞人之约后面，但没有年份，顺序不一定是时间顺序【未核实，不进剧本】；明写 “往歸” 的只有吴起（第四节）。
13. **魏桓子和魏文侯的关系**：魏桓子是爷爷（「魏斯者，桓子之孫也」（鉴1）；「桓子之孫曰文侯都」（史44））。《世本》说是父子，通鉴、史记取 “孙”。魏文侯名 “斯”（鉴1）还是 “都”（史44）也不一致，片子不写名字。
14. **一次性提醒**：Gemini 源文件里 “小人物的约定也是约定”“不能因地位悬殊而毁约” 这类说法，违反 10-01 规则，台词里改成平等的说法。

## 九、下集预告（按通鉴顺序）
下集是魏武侯浮西河、吴起 “在德不在险”，在**安王十五年（前 387）**那条，紧接着魏文侯去世：
- 「魏文侯薨，太子擊立，是為武侯」（鉴1）；
- 「武侯浮西河而下，中流顧謂吳起曰」（鉴1）；
- 武侯说：「美哉山河之固，此魏國之寶也」（鉴1）；
- 吴起答：「在德不在險」（鉴1；史65）；
- 吴起接着说：「若君不修德，舟中之人皆敵國也」（鉴1）（《史记》作 “盡為敵國”，见史65）；
- 武侯的回答只有一个字：善；
- 再往后是 「魏置相，相田文」（鉴1），吴起不高兴，要和田文比功劳（这件事是不是放进下集，到时候再定）。
- 吴起后来逃到楚国，被乱箭射死，整段不讲，不预告。
- 白话：武侯坐在船上，顺着大河往下，说 “这山河多险要，是咱们魏国的宝贝！” 吴起说：“靠的是德行，不是险要的地形。如果您不修德，船里的人也会变成敌人。”
- 通鉴里吴起接着举了三个例子（三苗、夏桀、商纣），句子里有 “滅”“放”“殺” 这样的字，下集只用一句话带过，比如 “他们的山河一样险要，后来都没守住”。
- **版本差别**：《战国策》里同一件事是另一个版本（网7）：武侯说 “河山之險，豈不亦信固哉” 并有大夫王鍾附和，吴起答 “吾君之言，危國之道也”，最后武侯说 “西河之政，專委之子矣”。通鉴用的是 “在德不在險” 的版本，片子照通鉴。
- 西河具体是哪一段河，不进剧本（鲍本补注引《正义》说是 “龍門河”，只有这一个来源，网7）【未核实，不进剧本】。通鉴写 “浮西河而下”，台词里可以说 “顺着大河而下”。
- **和本集的冲突**：武侯夸 “山河之固” 与 “魏国险阻最少” 矛盾（第七节第 7 条）。
- 预告可以这样说：“魏文侯去世了，武侯坐船游大河，夸山河险要——大将军吴起却说了一句扎心的话。”
