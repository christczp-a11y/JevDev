# 2D 布景：第 3 步的分层图怎么拼成 `video/sets/<名字>.json`

> 工作流第 0 步第 9a 项：**每个新地点都要有一份 2D 布景**。第 5 步的 `layout_qa`、`puppet_qa`、`logic_qa`、`selfcheck`，还有 3D 渲染，都经 `render.load_scene` / `assets_for` 读它；没有就直接报错（不会悄悄换成 `qin_gate`）。
> 真正的 tj01 布景要等第 3 步的图画完才做；这里只写做法和检查。

## 一、要放哪里、怎么检查

- 图：`video/assets/sets/<名字>/*.png`（第 3 步 Codex 出图、拆好以后放这里；JSON 里的 `dir` 写 `"sets/<名字>"`）。
- 布景：`video/sets/<名字>.json`，照 `qin_gate.json`（完整例子）或 `classroom.json`（最小例子）改。
- 检查：`python video/set_check.py <名字>`（不写名字 = 全部布景）。四层（`far`、`mid`、`stage`、`fore`）齐全、字段类型对、引用的图都在且打得开才退出码 0。
  场景 JSON 写好以后再跑 `python video/set_check.py --scenes video/scenes/<集>/shot*.json`：还会查每场的镜头走到哪里，各层画布够不够宽（不够宽，镜头一动就露出空白）。
- 看一眼：`python video/render.py <场景.json> --still 5 --out x.png`（2D 引擎出一帧）。

## 二、四层怎么画（`engine.html` 的 `buildSet` / `drawBand`，从后往前）

闯关画面是 1080×608 的横带，人物站的地面线 `GROUND = 500`。每一层是一张按 `width` 预先画好的画布，镜头在 `camX` 时这一层画在 `-camX × parallax` 的位置：视差越小越远、动得越慢。

| 顺序 | JSON 键 | 画什么 | 视差（秦国城门的值，各布景可以不同） | 摆件写法 |
|---|---|---|---|---|
| 1 | `far`（必须） | **一整张**宽图：天空 + 最远的山。引擎把它按 `far.height` 缩放，左右各一张拼成一条 | 0.12 | `img`、`parallax`、`y`（上沿）、`height`（显示高度）、`filter` |
| 2 | `hills`（可选） | 中间的山、远处的树，透明底剪影 | 0.33 | `items`：`[图名, 中心 x, 底边 y, 显示高度]`，x 是这一层画布里的坐标 |
| 3 | `mid`（必须） | 中景：城门、城墙、旗子、房子。`wallStrip` 用一节城墙无缝拼成整条，`gaps` 在城门洞后面留缺口；`behind` 画在墙后面；`fields` 是门洞里露出来的一块纯色 | 0.55 | `items`、`behind` 同上 |
| 4 | `stage`（必须） | 人物站的这一层：`ground` 一条左右无缝的地面（重复铺开）+ `items` 摆设。和人物同速 | 1（不用写） | `offset`、`width`、`ground`、`items`；x 是世界坐标 |
| 5 | 人物、道具 | 由场景 JSON 画，不在布景里 | | |
| 6 | `fore`（必须） | 前景：颜色暗，压住下缘，比人物动得快一点 | 1.35 | `items` |
| 7 | `frame`（可选） | 固定在画框上的纸框，不跟镜头动 | | `items`（可加第 5 项翻转） |

要注意的（`set_check` 会查的已标 ✅）：
- ✅ `far` 的图按 `far.height` 缩放后**宽度要 ≥ 1080**（视差为 0 的话 ≥ 540），否则镜头一动右边露空白。qin_gate 的远景 1672×941、`height` 660 → 宽 1173，刚够。
- ✅ `mid.wallStrip.img` 必须叫 `wall`：引擎只给这个名字存了拼城墙用的原图。
- ✅ 摆件（`hills`、`mid`、`stage`、`fore`、`frame` 的 items）要透明底；没有透明通道会警告，不然画面里会显出一个方块。
- ✅ 每层的 `width` 要盖住镜头走过的范围：`hills`、`mid`、`fore` 要 ≥ 1080 + 最大镜头位置 × 视差；`stage` 要盖住世界坐标 `最小镜头位置 … 最大镜头位置 + 1080`（`offset` 一般写负数，秦国城门是 −400）。
- 摆件的底边 y：中景放在墙脚 506 左右，前景放在 684–694（贴着画面下缘），`hills` 的树根 440（墙顶上方）；参考 `qin_gate.json`。
- `qa.pine`：画框左边有大树挡住多宽（像素），`layout_qa` 用它查「人物被松树挡」；没有大树的布景不写（教室就没有）。**有 `frame`（画框层）摆件、却没写 `qa.pine` 时 `set_check` 会警告**：画框边上挡住了多宽就写多少，确认不会挡住任何位置就写 `"qa": {"pine": 0}`。

## 三、第 3 步的竖屏 2.5D 分层图 → 2D 四层

第 3 步（工作流「布景按层画」、诊断文档第四节第 10 条）每个新地点按竖屏画 5–7 层：天空、远山（至少 3 层，越远越浅越蓝）、中景、主体、前景框（暗，压住下缘）；竖屏上下叠层，远山放上面 1/3。3D 里这些层是摆在书页上、离镜头不同距离的纸片；2D 里是同一批图按视差平移。**同一批 PNG 两边共用**，所以出图时就要把每层分成单独的文件、透明底（天空 + 最远的山除外）。

| 竖屏 2.5D 的层 | 出图要求 | 2D 布景里放在哪 |
|---|---|---|
| 天空 + 最远一层山 | 一张宽图，左右两边能接上；比横带宽（横向至少 1.8 倍高度） | `far.img`。竖屏的高图不能直接当 `far`：先裁成宽图 |
| 第 2、3 层远山（越近越深、越清楚） | 每层一张透明底的整条山，或几张剪影 | `hills.items`；层数多，就选 1–2 张放这里，其余合进 `far` |
| 中景（城墙、城楼、营帐、树丛、旗） | 每件一张透明底的图；长墙要能无缝接（左右同一个断面） | `mid.items`、`mid.behind`、`mid.wallStrip` |
| 主体层（人物站的地面和脚边的摆设） | 一条左右无缝的地面（透明底，上沿是草和土的边）+ 石头、灌木等摆设 | `stage.ground`、`stage.items` |
| 前景框（暗，压住下缘） | 暗色的灌木、树枝、栏杆，透明底 | `fore.items`；固定的纸框用 `frame` |

拼的步骤：
1. 把第 3 步过审的图放进 `video/assets/sets/<名字>/`，文件名用英文短名（`far.png`、`hills_near.png`、`gate.png`、`ground.png`……）。
2. 复制 `qin_gate.json` 或 `classroom.json`，改 `dir` 和 `about`（写清是哪个地点、每层放了什么）。
3. 先摆 `far`：`y` 和 `height` 让山脚落在 y≈440 附近（人物脚下的地面从 y≈500 开始）。
4. 再摆 `mid`、`stage`：摆件的底边 y 对着上面的表；横坐标按镜头要拍到的范围排开，人物出场的地方留空。
5. 最后摆 `fore`，压住画面下缘。
6. 跑 `python video/set_check.py <名字>`，再出几帧（`render.py --still`）看：接缝、悬空、门洞里是不是露出门外的景色（PITFALLS B2–B5）。
7. 3D 的布景数据（`stage.html` 的 `SETS`，第 0 步第 11 项另做）也用这批图，但摆法按竖屏 2.5D 重新排，和这份 2D JSON 各写各的。
