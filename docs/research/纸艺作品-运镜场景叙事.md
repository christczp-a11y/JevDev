# 纸艺类游戏和动画的运镜、场景、叙事技巧（2026-09-28）

## 二、运镜
1. **默认用书桌俯视的斜 45° 机位，关键时刻才切电影镜头。**【我的了解】纸片马力欧和耀西大部分时间用斜上方跟随的机位，像在看一个桌上的模型，画面稳、容易看懂；到了事件和高潮才推近、换角度。
   → 我们：每一页先用一个稳定的「书桌机位」交代场景（谁在哪），再切仰拍、俯瞰、特写这些镜头。这和调研里「看得懂才会一直看」一致。
2. **翻到背面揭示机关。**【资料】耀西的手工世界每一关都有「背面」：镜头转到场景后面，能看到固定纸板云的线和胶带、机关怎么运转，突出手工感。
   → 我们：讲「为什么」的时候，镜头绕到纸景背面。比如商鞅的 4 个诀窍（事情小、人人看见、当场兑现、赏金离谱）画成藏在纸景后面的「机关」，一个个转动起来。**核心问题的答案，就是场景背后的机关。**
3. **拉远：原来这是一本书。**【资料】千年之门开头是旁白读一本书；【我的了解】很多纸艺作品用拉远镜头揭示「这是一个模型或一本书」。
   → 我们：每集结尾镜头拉远，纸景变小，原来是司马光书桌上摊开的一页，然后接他的点题。
4. **过去的事用皮影或剪影讲，并故意加手持的抖动。**【资料】功夫熊猫 2 开场用金属皮影风格讲反派前史。制作时 After Effects 做出来太顺滑，他们特意加了卡顿和抖动，并把旋转轴点放高，像用杆子举着的皮影。
   → 我们：前史、回忆和**儿童不宜的情节**（比如三家分晋里豫让漆身吞炭、智伯头骨做酒器）用皮影剪影一笔带过，**既好看又能过儿童不宜的关卡**。纸偶动画可以加一点「手持」抖动，增加手工感。
5. **舞台框：观众坐在台下。**【资料】千年之门的战斗在剧场舞台上进行，台下有观众，幕布会挡住舞台边缘，整个游戏都在强调「这是一场演出」。
   → 我们：「考你」时刻切到一个小舞台，两边是幕布，台下纸片观众举牌、起哄。每次考题都是同一个舞台，形成固定仪式。

## 三、场景
1. **露出手工材料**：胶带、线、折痕、纸边（耀西【资料】）。纸艺的魅力在于看得出「是手做的」，不要做得太干净。
2. **框架场景**：书（千年之门、撕纸小邮差）、剧场（千年之门）、书桌（我们的司马光书房）。我们的三层是：**司马光书房 → 摊开的书 → 书页上的立体纸景**。
3. **纸是会变的材料**【我的了解，待核实】：折纸国王里，敌人是折纸做的士兵，巨大的彩带缠住城堡作为目标，用纸屑补地上的洞。
   → 我们：破掉的东西用纸屑补回来。第 1 集的「信用心」裂开后，可以用纸屑一点点补回去，**补的过程就是看得见的进度**。
4. **能打印的手工**【资料】：任天堂为耀西的手工世界发布了可打印的立体模型套件（连「背面」都能设计），撕纸小邮差也能收集纸模型打印出来。
   → 我们：每集附一张可打印的人物纸模（司马光、本集主角），家长和孩子可以一起做。**这是小红书的收藏动机，也是以后做周边的雏形。**

## 四、叙事
1. **框架叙事：讲故事的人在读书。**千年之门（旁白读书）、功夫熊猫 2（算命婆婆用皮影讲）。我们让司马光读他自己写的书，这个方向是对的。
2. **打破第四面墙，观众也是角色。**【资料】撕纸小邮差把玩家本人（「你」）写成故事里的角色。我们的「考你」，以及司马光指着镜头说话，就是同一个思路。可以更进一步：把观众的选择画进纸景里，比如按钮是一张可以翻开的纸牌。
3. **纸本身就是笑点。**【我的了解】纸片马力欧的角色常拿「自己是纸做的」开玩笑：被压扁、揉成团、被风吹走。
   → 我们：笑点可以来自纸的物理（司马光被风吹得贴在书页上、乌鸦把告示啄出一个洞），但按调研的规定，**只在动作上夸张，不改史实**。
4. **分章节，有一个固定的中心场景。**【资料】千年之门是分章节结构，有一个中心城镇把各章串起来。
   → 我们：每集是一章，中心场景是「司马光的书房」。书架上摆着已经讲过的故事，墙上贴着收集到的人物卡，片头片尾都从这里进出。
5. **剪纸传统的删繁就简。**【资料】葫芦兄弟把剪纸的装饰性和二维动画结合，删繁就简，五官、脸型、穿着反映性格，节奏明快。和我们的角色设计规范（剪影、主色、形状就是性格）一致。

## 五、给云端的补充（加到画面改版任务书里）
- 每一页的镜头顺序：**书桌机位交代 → 电影镜头（仰拍 / 俯瞰 / 特写）→ 讲「为什么」时翻到背面看机关 → 结尾拉远回到书桌**。
- 回忆、前史、儿童不宜的内容：用皮影剪影，加手持抖动。
- 「考你」：固定的小剧场，有幕布和台下观众。
- 修补类的进度（信用心）：用纸屑补回来。
- 每集一张可打印的人物纸模（小红书图文用）。
- 第 0 步查证时，把本文标【我的了解】的几条一起核实：折纸国王的默认镜头、彩带、纸屑补洞、纸片自嘲的笑点。
