# 剪辑节奏和特效（少儿版「古人云」）

> 用在第 4 步写分镜表、第 6 步合成。依据：古人云视频拆解（2026-09-29，本地逐帧）、`docs/短视频留存-调研与ep01重构建议.md`、`docs/儿童动画吸引力原理.md`、`docs/research/儿童短视频-10个爆款拆解.md`、`docs/research/纸艺作品-运镜场景叙事.md`，以及上美影和纸片马力欧的镜头研究（见 git 历史里的诊断文档）。

## 一、我们做的是什么
**动态漫画**：画面是 Codex 画的整幅插画或分层插画，「动」靠四样东西：
1. 镜头运动：推、拉、摇、移、震；
2. 人物换表情和小动作：弹、挤压、晃、点头、呼吸；
3. 特效叠层：速度线、贴纸、砸字、粒子；
4. 剪辑节奏：切点卡在台词和音乐上。

古人云有动感，靠的就是这几样的密度，不是画面本身在做动画。我们照这个思路做，但是：
- 画风是我们的纸艺手绘；
- 梗换成孩子的生活；
- 节奏比它慢一点，保证孩子看得懂；
- 不要血腥和恐怖。

## 二、节奏（硬指标）
| 项目 | 指标 |
|---|---|
| 画面变化 | 平均每 2–3 秒一次「视觉变化」：切镜头、换表情、弹出特效、镜头明显变向，都算。任何画面静止不超过 1.5 秒（镜头至少在缓慢推拉） |
| 镜头数量 | 每分钟约 18–24 个镜头（古人云实测 19–28，孩子要看得懂，我们取偏慢的一头），镜头长度中位数约 2–2.5 秒 |
| 一句一镜 | 台词一句一个画面或一个变化（换镜头、换表情、弹贴纸）。台词写短（见《钩子和吸引力》的台词风格），节奏才快得起来 |
| 单个镜头长度 | 一般 1.5–4 秒；讲知识点、清单、结尾那句真心话可以到 5–7 秒，每集这种长镜头不超过 6–8 个，镜头里要有缓推，文字逐条出现 |
| 快切 | 只用在高潮和「燃」的段落：每镜 0.8–1.2 秒，连续不超过 5 个，之后要回到正常节奏 |
| 讲知识点时 | 画面上新出现的东西最多 2–3 样；不快切，不闪白，不堆特效 |
| 笑点 | 每 15–25 秒一个，放在知识句前面或中间，不压在知识句上 |
| 新信息 | 最多每 10–12 秒一个新节拍；没有信息的空白不超过 3 秒 |
| 开头 | 前 3 秒至少 3 次视觉变化（见《钩子和吸引力》） |

每一场的景别顺序（上美影的做法）：远景交代在哪 → 全景人物入画 → 中景说话 → 特写表情或道具 → 回到全景。相邻两个镜头最多跳两档。

## 三、镜头运动（代码实现，全系列统一参数）
| 名称 | 用在哪 | 参数（起步值） |
|---|---|---|
| 缓推 / 缓拉 | 默认，每个镜头都要有 | 整个镜头放大 3–8%，用平滑曲线（smootherstep） |
| 摇 / 移 | 交代环境、跟着视线 | 每秒移动不超过画面宽度的 15% |
| 分层视差 | 有分层素材的全景 | 远景 0.1–0.3，中景 0.5–0.8，主体 1.0，前景 1.2–1.4 |
| 冲击推（zoom punch） | 重音、揭晓、「！」 | 0.15 秒内放大 8–15%，再用 0.3 秒回弹一半 |
| 震屏 | 撞击、拍桌、大声 | 0.25–0.4 秒，振幅不超过画面宽度的 1.5%，衰减 |
| 甩镜转场（whip pan） | 换场 | 0.2 秒，加运动模糊 |
| 呼吸漂移 | 静态画面防「死」 | 振幅 3–6 像素、周期 3–5 秒，全片统一 |

**不做的**：绕到人物侧面或背面（纸片画没有背面）；一个镜头里同时又推又摇又震。

## 四、人物表演（不画动画，也要有戏）
- **换表情就是表演**：主角每人一套 6–8 个表情（得意、生气、惊讶、害怕、哭、想、笑、坏笑），一换表情就配一个小弹跳和音效。
- 说话时：人物随句子轻轻上下起伏（2–4 像素）；只有说话的人在动，其他人保持呼吸漂移。
- 出场和退场：从画外滑进来、从地上「弹」起来（带过冲）、翻纸片翻进来。
- 反应镜头：一句重要的话以后，切到听的人的特写和表情（孩子最爱看反应）。
- 夸张只用在动作和表情上，**史实一个字不改**。

## 五、特效包（系列统一，写在代码里，每集直接调用）
| 类别 | 特效 | 什么时候用 |
|---|---|---|
| 漫画线 | 放射速度线、集中线、横向速度线 | 惊讶、冲刺、「燃」、揭晓 |
| 贴纸 | 问号、感叹号、灯泡、汗滴、怒气符号、星星眼、小心心、「咚」「啪」「嗖」拟声字 | 反应和笑点。纸贴纸风格，带白边，弹出 |
| 砸字 | 关键词一个字一个字砸下来，带震屏 | 关键词、数字、结论 |
| 清单 | 一条条弹出（带打勾或星星） | 本事、理由、功绩 |
| 属性卡 | 游戏属性条，例如「本事 ★★★★★ / 好心 ★」 | 讲人物；少儿版的「技能面板」 |
| 地图 | 纸地图，虚线箭头一点点画出来，城标弹出 | 讲地理、行军、谁要谁的地 |
| 转场 | 翻书页、纸片擦过去、墨笔刷擦过去、圆圈收拢、淡到纸色 | 换场、换时间 |
| 氛围 | 光芒、闪粉、纸屑彩带、灰尘、雨、水花、纸剪火焰 | 高潮、胜利、天气 |
| 调色 | 回忆：旧纸黄 + 颗粒；紧张：稍暗、加暗角；不用血红 | 前史、危险 |
| 闪 | 柔和闪白（最多 60% 亮度、2–3 帧） | 重大揭晓，一集最多 3–4 次 |
| 考你 | 「考你！」按钮 + 倒计时圈 +「看答案！」 | 系列仪式，每集 4 次 |
| 进度物 | 本集的概念物（例如水位刻度），变化时弹一下 | 每集一个 |
| 人物卡 | 片尾收藏卡：头像、名字、一句话、属性 | 每集结尾，系列收集 |
| 人名牌 | 人物第一次出场：旁边竖排书法大字写名字，下面一行小字写身份（「智家老大」），用家族颜色 | 每个人物第一次出场 |
| 游戏卡片 | 「任务：守住晋阳」「任务失败」「获得称号：最会忍的人」「本集 MVP」，纸卡弹出 | 关卡开始和结束、揭晓 |
| 大字标题 | 「第 1 关：忍」「水，倒过来了！」这类大字，配光芒或纸剪火焰 | 关卡开头、燃点 |
| 解说台 | 司马光坐在书房的纸片解说台后面，拿着遥控器和话筒，按一下，画面切到故事里（游戏解说的感觉） | 串场、开场、点题前 |
| 颜色分段 | 每一段一个主色调（得意用金色，密谋用蓝色夜晚，从前用旧纸黄，胜利用暖色），换段就换色 | 换场、换时间 |

每个特效都配**固定的音效**。全系列同一个特效用同一个声音，孩子一听就知道「要来了」。

**场景复用（省画，也省钱）**：一个大场景画一张（比如蓝台宴会、晋阳城头、智伯营帐），靠不同的裁切、推拉，加上人物换表情，撑起 5–10 个镜头。古人云就是一张地图室、一个指挥台撑大半集。不要每个镜头都画一张新的。

## 六、声音就是节奏
- 切点、弹出、砸字卡在台词的字上，或者音乐的拍子上（合成器按配音时间线对齐）。
- 三层声音：配音（最响）→ 音效 → 背景音乐（有人说话时自动压低）。
- 「燃」段换成节奏更强的音乐片段；知识点段音乐放轻。
- 整集响度目标 −16 LUFS，峰值不超过 −1.5 dB。

## 七、儿童安全（和节奏一起检查）
- **闪烁**：任何 1 秒内不超过 3 次闪烁（WCAG「三次闪烁」标准）；不用红色大面积闪；不用反色闪。
- 不用血、刀光、发红光的眼睛、恐怖剪影、「杀、吃人、死」这类字眼上屏（「作死」这类口语可以，09-30 Chris）。
- 「燃」可以有：光芒、速度线、战旗、大字，但不做恐怖和暴力。
- 贴纸和梗只用孩子的生活：校园、作业、零食、排队、奖状、兄弟姐妹。不用网络烂梗、脏话、成人梗。
