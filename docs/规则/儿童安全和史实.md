# 儿童安全和史实（红线，每集必查）

## 内容
- **故事核心就是暴力的**（刺杀、酷刑、杀妻，比如豫让、聂政、吴起杀妻）：视频整段跳过，只在正文里用一两句交代（Chris 09-29）。
- 画面上不出现血、伤口、尸体、刀砍、恐怖的脸，不画淹死、挣扎求救的惨状；不把「杀、吃人、死」这类字放上屏幕。**09-30 Chris 放宽**：人可以泡在水里、被浇成落汤鸡、抱着木头划水，只要不涉及生死和血腥（也符合史实，的确被泡）；「作死」「红温」这类孩子都懂的口语可以用。战争只画旗子、营帐、四散的兵、大水冲垮营帐。
- 不制造两代人对立：不把现实里的家长、老师演成反面。历史人物做对手时，写成「骄傲、不听劝、最后倒霉」，不丑化、不恶搞。
- 不叫观众「孙子」；不用网络烂梗、脏话、成人梗（比如「老铁」「没逝吧」「熊孩子」「你他娘的」「你不要过来啊」）；不做现代货币换算。
- 不说杀了多少人、斩首多少；不夸扩张、不夸征服。讲的是计谋、选择和结果。
- 不用真人照片、换脸，不用影视剧截图（版权问题，风格也不统一）。
- 现代的东西不放进历史场景、不放在古人手里；只能出现在司马光的解说台、想象泡泡和贴纸里。**例外（09-30 Chris）**：眼镜、名牌这类一眼就懂的现代化形象表达，可以用在人物造型上（大家都知道古人没有，是表达手法）；名牌用编出来的标志（比如满身印「智」字的花纹），不用真实品牌的商标。

## 画面
- **闪烁**：任何 1 秒内不超过 3 次闪烁；不用红色大面积闪；不用反色闪（合成器自动检查）。
- 不做让孩子害怕的画面：发光的红眼、黑影压过来、突然的尖叫音效。
- **声音也不能吓人**：每个角色的声音都要温暖、明亮、带笑；老人是慈祥爽朗的爷爷，不是阴沉沙哑的老头；反派只是傲慢、洪亮，不阴冷（PITFALLS A7）。
- 字一律用简体；生僻字截图检查有没有缺字。

## 史实
- 所有台词对照 `video/stories/<集>/source.md`；标【未核实】的不进剧本（`source_check.py`、`story.py` 的史实闸门）。
- 只夸张动作和表情，**不改史实、数字、结局**。按画面比例改了尺寸的，在正文里说明。
- 朝代器物服饰按简报清单画：没有元宝、没有方孔钱（前 336 年以后才有）、没有马镫和骑兵队（战国早期）、没有椅子和纸书（古人），城墙是夯土不是砖。
- 片子里不说查不实的细节（河名、围了多久这类）；人名一律用通鉴的写法。
