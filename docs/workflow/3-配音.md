# 第 3 步：配音和时间线

谁做：`ep-builder`（Sonnet 5.5 xhigh）。要在分镜表之前做，这样导演拿得到每一句的真实时长。
引擎：**Qwen3-TTS**（本地显卡，独立环境 `.venv-tts`）。只在本地跑，配音时关掉别的吃显卡的程序（显存很紧）。一集第一次约 20–25 分钟，之后大多走缓存。

## 做法
- `python video/voice.py <定稿剧本> video/out/<集>_voice [动作行号=秒 ...]`，完整命令记进 status.md。
- 旁白和司马光的声音、仪式录音在 `video/series_voice.json`；本集角色的声音在 `episode.json` 的 `cast`（角色 → 声音描述）。第一次用到的角色会自动设计参考音，存进 `video/assets/audio/voices/`，以后都用这段参考音克隆，同一个人前后声音一样。改了描述要 `--redesign 角色`；系列声音用 `--make-series-voices`，仪式录音用 `--make-ceremony`。
- 声音描述要温暖、明亮、带笑；不许写「低沉、沙哑、气声、阴森、阴沉、神秘」这类词，`voice.py` 会直接报错（PITFALLS A7）。
- 语气写在剧本顶层的 `tone`（台词原文 → 语气，比如「得意、霸道」「压着火气、小声」），导演在第 2 步写好。每个（角色，语气）第一次出现时会另设计一段参考音，存成 `<角色>@<语气>.wav` 复用。
- 读错的字：在剧本顶层写 `voice_text`（原文 → 同音字），字幕仍用原文。
- 动作行号从 0 数；缓存自动按文字判断，改了台词直接重跑。

## 过关
- `python video/script_check.py <定稿剧本> --timeline video/out/<集>_voice/timeline.json` 退出码 0；
- `python video/story.py video/stories/<集> --only <定稿> --timeline video/out/<集>_voice/timeline.json` 的最长平淡段不高于基线。
