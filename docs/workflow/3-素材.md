# 第 3 步：人物、布景、道具

谁做：builder 用 Codex 画，自己跑脚本检查。不派 reviewer。

## 规则
- 先查 REGISTRY.md：定稿过的人物直接用；新前缀不许重名；「停用」栏的素材不许用。
- **全部重新画，按竖屏 2.5D 分层画**，不拿试做集的素材凑（T19）。
- 新角色：Q 版 2–3 头身；剪影一眼认得出；一个主色 + 一件标志物（主色避开司马光的紫）；形状体现性格；传统纹样只做镶边，不照搬戏曲造型。
- 一集里有几家人时，每家一个颜色和一面简单的旗（全系列沿用，写进 `video/series_style.json`）。
- 古人一律**交领右衽、席地跪坐、竹简**；圆领、幞头、椅子、纸书只属于司马光。
- **布景按层画**：天空、至少 3 层远山（越远越浅越蓝）、中景、前景框（暗，压住下缘）。每层的尺寸要够推拉：屏幕显示 ÷ 原图 ≤ 1.3。每个新地点画的图要够拼出一份 2D 布景。
- **要拍特写的人和道具，另画一张高清图**（现在的姿势图只有约 500 像素高，T14）。
- 每张图在 REGISTRY.md 登记**原图朝向**（左 / 右 / 正面，T13、T17）。
- 主角的素材不许当路人用；路人另画，颜色和主角、背景分开（T16）。
- 默认画姿势图（每人约 5 个姿势）；只有动作很多的角色才做纸偶关节。
