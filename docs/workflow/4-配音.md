# 第 4 步：配音和时间线

谁做：builder。不派 reviewer。第 3 步和第 4 步可以同时做。
相关坑：S10、A5、E3。

## 做法
- `python video/voice.py <定稿剧本> video/out/<集>_voice [动作行号=秒 ...]`。完整命令记进 status.md。
- 旁白和司马光的声音、句间停顿、仪式录音都在 `video/series_voice.json`，不用另外设；本集角色的声音写在 `episode.json` 的 `cast`。
- 两句仪式句（司马光「考考你！」、旁白「写书的人，来了——」）要单独成句、一字不差，才会用系列录音。
- 读错的字：在剧本顶层写 `"voice_text": {"原文": "配音用的同音字"}`，字幕仍然用原文。
- 动作行号从 0 数；剧本增删行以后要按新的行号重写。
- 缓存按文字、声音、语速、音高自动判断，改了台词直接重跑同一条命令。

## 过关
都按配音以后的真实时长算：
- `python video/script_check.py <定稿剧本> --timeline video/out/<集>_voice/timeline.json` 退出码 0：大问题 7 秒内念完、「考你」停顿依次 1.0 / 1.2 / 1.2 / 1.8 秒、语速 ≤ 每秒 5 字、金句 3 次等；
- `python video/story.py video/stories/<集> --only <定稿版> --timeline video/out/<集>_voice/timeline.json`：最长平淡段不高于 status.md 里记的基线；它列出的「没有台词、超过 4 秒的动作段」，除了悬念段都要改。
