# 第 1 步：选题和史料

谁做：`ep-researcher`（Sonnet 5.5 medium）查资料，主会话把报告原样存成 `video/stories/<集>/source.md`。
读：本文件、`docs/规则/儿童安全和史实.md`。

## 选题
- 按《资治通鉴》顺序，下一个完整、可以讲的故事。
- 故事核心就是暴力的，整段跳过，接后面那个。
- 集号：`tj<两位集号>`（第一集三家分晋 = `tj01`）。

## 简报里要有
1. 原文段落（维基文库《資治通鑑》，再用《史记》等交叉核对），每处引文 ≤ 20 字、附出处短码；
2. 事件时间线，标出哪些是追述；
3. 人物表：做了什么；画的时候注意什么；人名、地名注拼音，标出多音字；
4. 「臣光曰」的白话意思和点题用的原文短句；
5. 儿童不宜清单和处理办法；
6. 常见误传；
7. 朝代器物服饰清单（有什么、没有什么）；
8. 下集预告：下一个可以讲的故事。
