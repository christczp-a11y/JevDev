# 系列风格规范（每集必须一样）

这些是系列的「脸」，只写在公共代码里，数值以代码为准，不许挪进每集的配置。要改其中任何一项，先问 Chris，再记进 DECISIONS。

| 项目 | 现在的值 | 定义在哪 |
|---|---|---|
| 格式 | 1080×1920，每秒 30 帧 | `video/stage3d/build_stage3d.py` |
| 版面 | 顶部卷号标签；计分牌在标签下面；人物安全区 y 270–1440、左右各留 7%；字幕框中心 y≈1600，上面是说话人标签 | `stage.html` 的 `drawUI`、`SAFE` |
| 字体 | 标签和说话人用 ZCOOL KuaiLe；字幕用 Noto Sans SC 700（放在仓库里） | `video/vendor/fonts/`、`engine.html`、`stage.html` |
| 色板和纸感 | 墨 `#2a2320`、红 `#c8372d`、米 `#f4e8d0`；厚白纸边、纸纹；人物饱和度 0.85，背景更低 | `engine.html`、`puppet.js` |
| 画风 | 纸艺立体书、Q 版 2–3 头身、扁平手绘、粗白纸边 | `video/assets/ref/paper_style_ref.png`、`codex_ep01/sgm_v2.txt` 第一段 |
| 家族颜色和旗 | 第一集定，全系列沿用 | `video/series_style.json` |
| 人声 | 旁白 XiaoxiaoNeural +6%；司马光 YunxiNeural −10% −12Hz；「考考你！」「写书的人，来了——」每集用同一段录音 | `video/series_voice.json`、`video/assets/audio/` |
| 音效和音乐 | 提问音、揭晓音、进度 +1 全系列不换；背景音乐一首，说话时压低 | `video/audio.py`、混音代码 |
| 结构 | 开头 0–5 秒模板、「考你」仪式、三关、金句 3 次、结尾顺序 | `2-剧本.md` |
| 镜头语法 | 正对舞台、偏转 ≤ ±15°、镜长、景别顺序、人物占比 | `6-舞台镜头.md` |

参考帧在 `video/assets/ref/series/`，**只用来比界面层**：标签、计分牌、字幕框、字体、选择题、横幅、纸边。镜头和布景层次不比参考帧，按 `6-舞台镜头.md` 查。
