# 第 2 步：剧本

谁做：builder 写，Jev 打分。默认不派 reviewer（规矩第 2 条）。
读：`video/stories/<集>/source.md`、`要点.md`。相关坑：S1、S3、S7、S9–S11、S13、S15、P10。

## episode.json
`core_question`、`core_answer`；`source`（本集用到的原文，按简报顺序整段抄，转简体：Jev 的史实闸门只对照它）；`trick`（至少 2 条「为什么」，写对手的办法为什么管用）；`pitfalls`（抄简报的误传清单 + 本集硬规定）；`cast`（本集角色的声音，旁白和司马光不写）；`banned`（禁用词 → 原因）。

## 写几版
先写 **3 版**候选，格式照 `video/stories/ep01/N6_*.json`，每句都写估算的开始、结束秒。不够好再加。
每版先跑 `python video/story.py video/stories/<集> --lint --only <版本>`（不调 Jev），再用 `--pairs` 比较。

## 结构（全系列固定）
- **开头 0–5 秒**：0–1 秒司马光从书页弹出来「考考你！」→ 1–3 秒本集最怪的一幕 → 3–5 秒二选一加倒计时。7 秒内念出大问题。这三拍是剧本节拍，不是三个镜头：画面上第一个镜头从 0 秒起就有司马光，至少 3 秒（T11、T12）。
- 一个大问题贯穿全集；节拍之间用「但是 / 所以」，不用「然后」；三关一关比一关难。大问题在 40%–60% 处关闭，关之前先打开下一个问题。
- 一个视角人物贯穿三关（不用小豆子）。
- 「考你」约 4 次，同一套仪式；停顿依次 1.0 / 1.2 / 1.2 / 1.8 秒，停顿时画面不静止；揭晓只说「看答案！」。
- 金句只有一句，≤ 12 字，全集说 3 次。
- 每 15–25 秒一个小笑点，不压在知识句上。
- 结尾：「写书的人，来了——」→ 司马光用「臣光曰」点题（≤ 10 秒）→ 落到孩子的生活 → 一个笑点或温暖画面 → 下集预告。
- 只夸张动作和表情，不改史实、数字；不做现代货币换算；不制造两代人对立；历史人物做对手时写成「骄傲、不听劝、最后倒霉」，不丑化。
- 删掉铺垫，就同时删掉回收。时长 2–3 分钟，不卡秒数。

## 过关
- `story.py` 报告里定稿版 `g_accuracy`、`g_kid_unsafe`、`g_generation` 都 < 0.5（它只打分不拦截，要读 `report.json`）；最长平淡段不高于 status.md 里记的基线；两两对比胜出。
- `python video/script_check.py video/stories/<集>/<剧本>.json` 退出码 0。
