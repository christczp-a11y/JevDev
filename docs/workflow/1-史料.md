# 第 1 步：史料简报

谁做：researcher 查，主会话把报告原样存成 `video/stories/<集>/source.md`。不派 reviewer：由脚本核对引文。
相关坑：S2、S4–S6、S8、S13、S14、S15。

## 选题
- 按《资治通鉴》顺序，不挑着讲。
- 唯一的例外：**故事核心就是暴力的**（刺杀、酷刑、杀妻，比如豫让、聂政、吴起杀妻），视频整段跳过，直接接下一个故事，只在给家长看的正文里交代一两句（Chris 09-29）。

## 简报里要有
1. 原文段落：维基文库《資治通鑑》，再用《史记》等交叉核对。每处引文 ≤ 20 字，附出处。
2. 事件时间线：哪些是本年的事，哪些是追述。
3. 人物表：谁、做了什么、画的时候注意什么。人名、地名注拼音，标出生僻字和多音字。
4. 「臣光曰」的白话意思，以及给司马光点题用的原文短句。
5. 儿童不宜清单，每条写处理办法：整段跳过 / 不讲这个情节 / 皮影一笔带过 / 只说「罚了」。
6. 常见误传清单。
7. **朝代器物服饰清单**：这个时代有什么、没有什么（钱币、帽子、衣领、兵器、坐具、地图）。第 3 步画素材要用。
8. 下集预告：通鉴里紧接着的下一个**可以讲的**完整故事。
