# 第 8 步：按 Chris 的意见修改

谁做：主会话派活，builder 改。只有改动大的时候，才按第 7 步再做一次成片检查。
相关坑：P4、P2、P3，以及 Chris 这次说到的那几条。

## 先分类，决定从哪一步改
- 画面、站位、镜头、动作 → 从第 5 或第 6 步改，只重渲受影响的场；
- 改台词、加减句子 → 从第 4 步重新配音，后面各场的声音都要重混；
- 讲法、结构、大问题 → 回到第 2 步重写，不在这里一条条补。

## 每一轮
1. 主会话先在 `memory/PITFALLS.md` 记一行（Chris 的原话 + 日期）；老问题再犯的，在原行记「再犯」。
2. builder 改，一轮意见一次改完，不要改一条发一次。
3. 跑受影响那几步的脚本质检，再做改前改后对比：场景 JSON 改了用 `selfcheck.py --base <上次交付的提交>`；3D 布景和镜头改了用第 0 步第 20 项的对比工具。所有变化的地方都要看（P4）。
4. **只重渲改过的场**：`git diff --stat <上次交付的提交> -- video/scenes/<集>/` 里变了的场，加上镜头表改过的场；改了公共的东西（`stage.html`、`engine.html`、`puppet.js`、素材图）就全部重渲。
5. 发给 Chris：带声音、每秒 30 帧的片段，附一句「这一版改了什么」。
6. 修好以后，回到 PITFALLS 那一行补上根因、规则和自动检查。

目标：每一轮 ≤ 10 分钟。
