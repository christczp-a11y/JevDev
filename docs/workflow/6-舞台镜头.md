## 镜头
1. 镜头基本正对舞台：左右偏转 ≤ ±15°，最多 ±20°；**不绕到侧面和背面**，只做平移和推拉。用长焦，视野角约 15–25°，同一场里不变。俯角：交代镜头 25–35°，对话镜头 ≤ 15°。
2. 每个镜头 ≥ 2 秒，交代镜头 ≥ 3 秒，一般 3–5 秒。动的镜头约占 1/5，只用来揭示、跟随动作和拍高潮；其余镜头里也要有很慢的推或拉，不要死定住再硬切。选择题、知识点、点题时机位不动。
3. **景别按剧情定，不按人数定**：远景交代 → 全景入画 → 中景对话 → 特写表情或道具 → 回全景。相邻两个镜头最多跳两档。人物在画面里的高度：宽镜头 10–15%，中景 25–30%，特写 ≥ 50%。
4. 每场定一条轴线（我方在左，对方在右），机位留在同一侧；先看后切：人物先看，下一个镜头切到他看的东西。**旁白说到谁，谁就是画面主体。**
5. 第 1 场：第一个镜头从 0 秒起就有司马光，至少 3 秒，他从书页上弹起来（不用 2D 的书卡道具）。
6. 拉远回书桌（`pullback`）一集只用一次，放在点题之后。
7. 跟拍镜头按固定的身体范围构图，相机位置要平滑，不许每帧按像素外框重算（T20）。
8. 自动构图 `fit` 只负责入画：说话的人 ≥ 75% 在画面里，镜头对准的人 ≥ 85%。

## 场景
- 立体书摊在司马光的书桌上，一场就是一页；换场时这一页折倒，下一页弹起来。
- 每场分 5–7 层：天空、远山（越远越浅越蓝）、中景、主体、前景框。背景的饱和度比人物低一档。
- 景深只用在中景和特写；**宽镜头不虚化**，一虚化就像微缩模型，显得小气。
- 光源固定；有城门的布景，城墙只砌在城门两边；群众直接站在地上。
- 2D 的道具和特效搬进 3D 之前，先想一遍在 3D 里合不合理：书卡、会飞的乌鸦、悬在空中的牌子（T12）。

## 角色
- 按 REGISTRY.md 登记的原图朝向决定翻不翻：角色面向镜头主体或说话的人，对话双方面对面。
- 纸片在特写里不转身；要别的角度，就切一个镜头、换一张姿势图。
- 屏幕高度 ÷ 原图高度 ≤ 1.3；特写用高清图。脚底贴地，加接触阴影。
