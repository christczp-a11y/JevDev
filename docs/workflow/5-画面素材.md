# 第 5 步：画面素材（Codex）

谁做：`ep-builder`（Sonnet 5.5 xhigh）照素材清单调 Codex 画图。
读：本文件、`docs/规则/版式和画风.md`、`素材清单.md`、`source.md` 的朝代器物服饰清单。

## 做法
- Codex 素材引擎：**`gpt-6.1-sol`，reasoning high**（Chris 09-29 定：比 astra 更干净，字更清楚，额度也更宽）。一律用系列脚本 `bash video/codex_gen.sh video/assets/codex_<集> <名字> <参考图...>`：读 `<名字>.txt`，写 `<名字>.png`。可以几张一起并行画。
- 附图：`video/assets/ref/paper_style_ref.png`，加一张已定稿的同一角色图，保证长得一样。
- 提示词第一段照 `video/assets/codex_ep01/sgm_v2.txt`：扁平手绘、纸纹、粗白纸边，不要 3D、不要黏土质感；写上朝代禁忌（交领右衽、没有元宝）。
- 整幅镜头画：提示词里写清构图、谁在左谁在右、各自朝哪边、表情。
- 表情组：同一个人一张表格画 6–8 个表情，绿底。拆图：绿底用 `split_sheet.py`，透明底用 `split_alpha.py`。
- 每张图都登记进 `video/assets/REGISTRY.md`：朝向、尺寸、状态。
- 先画主角的表情组和第一场的图，这样合成可以提前开工。
- 系列贴纸已经画好（`video/assets/codex_series/stickers_v1.png`，9 个），不用每集重画。
- 画完 builder 自己放大检查：纸边完整、没有多余的字、手指和帽子正常、人物前后长得一样。画坏的直接重画这一张，不用送审。

## 过关
- `python video/registry_check.py` 退出码 0；
- `python video/board_tj01.py lineup` 这类总览图（以后改成按集的版本）拼出来，builder 自己看一遍：画风一致、朝代没错、一个人只戴一顶帽子。
