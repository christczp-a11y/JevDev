# 第 5 步：分场和站位

谁做：builder。不派 reviewer。要等第 3、4 步都做完。
相关坑：B6、B7、R2、R5、R7、R8–R11、S4、T16。

## 做法
- 分场脚本 `video/build_<集>.py`：`CFG = eb.load_config("<集>")`，每场写一个 `def shotN(ep)`，最后 `eb.main(CFG, SHOTS)`。本集的常量（TITLE、LABEL、B、PX、NAMETAGS、QA）在 `video/episodes/<集>.py`。
- 检查配置：`python video/episode_build.py <集> --check-config --strict`。
- 生成：`python video/build_<集>.py [--only 2,3] [--shots 1] [--no-render]`（`--shots 1` 只做第一场，出样片用）。
- 场景 JSON 由脚本生成，不手改。时间用台词行号和台词里的词来定位。
- 片头角标按卷写（tj01 =「资治通鉴 · 卷一」）。
- `speaker` 写字幕上显示的名字；同一个人分几段出场，每个 id 写同一个 `speaker`。
- 画面上的字一律用简体。
- 人物第一次出场时出人名牌。
- 主角和有台词的角色不当路人（T16）。
- 每集一个「看得见的概念物」（试做集是信用心，tj01 是水位刻度）。

## 过关（Git Bash）
1. `python video/layout_qa.py video/scenes/<集>/shot*.json` 退出码 0（重叠、重影）；
2. `python video/glyph_check.py video/scenes/<集>/shot*.json` 退出码 0（缺字）；
3. 每场跑 `python video/logic_qa.py video/scenes/<集>/shotN.json`，最后一行是「0 个确定有问题」。3D 集里背景类的结论不算，3D 背景以第 6 步的 `qa` 为准；
4. 有纸偶关节的场：`puppet_qa.py` 全闭、`--eyes=0.4` 半闭各跑一次；
5. `python video/registry_check.py video/scenes/<集>` 退出码 0（停用素材、元宝、方孔钱）。
