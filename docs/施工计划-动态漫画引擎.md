# 施工计划：动态漫画引擎（一次建好，之后每集复用）

> 2026-09-29 定：不用 three.js，不用 AI 视频。画面 = Codex 画的插画；动 = Python 合成器 + 特效包。
> 原型：`video/motion/_prototype_mc.py`，也就是 09-29 给 Chris 看的 17 秒小样。它能跑，但写死了镜头。施工就是把它变成「读分镜表就能出片」的通用引擎。

## 一、技术选型（已定，不再讨论）
- Python（`.venv`）：numpy 加 OpenCV（`cv2.warpAffine`、模糊、合成，比 PIL 快得多）；Pillow 画字；ffmpeg 编码和混音。
- 按镜头多进程并行渲染；每个镜头按输入内容的哈希缓存，没变的镜头直接复用。
- 结果可复现：同样的输入，出来的每一帧都一样；随机数一律带固定种子。
- 不需要浏览器，不需要显卡，云端和本地都能跑。
- 字体：全量 TTF / OTF 放进 `video/vendor/fonts/`（Noto Sans SC Bold、ZCOOL KuaiLe，SIL OFL）；找不到字体直接报错，不许退回系统字体。
- 背景音乐：`video/assets/audio/bgm_main.mp3`（现在的曲库曲子，Chris 09-29 同意可以发布），提交进 git；找不到就报错。
- 配音：`video/voice.py`，引擎是 Qwen3-TTS（开源、本地显卡、每个角色一个设计好的声音，每句可以写语气），不属于合成器施工，已单独接好。
- 素材：Codex `gpt-6.1-sol` high，统一脚本 `video/codex_gen.sh`。

## 二、目录
```
video/motion/
  render.py            读分镜表出片：--preview（半分辨率）/ 默认整集 / --final（发布版：高码率、慢编码）/ --shots 1-1,1-2
  storyboard_check.py  分镜表检查（第 4 步的过关脚本）
  fx/                  特效包：一个特效一个函数，参数统一
  sfx/                 系列固定音效（程序合成，不用来源不明的素材）
  stickers/            系列贴纸（Codex 画一次，登记进 REGISTRY）
  tests/               测试和坏样例
  README.md            用法、分镜表字段说明、特效清单
```

## 三、分镜表格式（`video/stories/<集>/storyboard.json`）
```json
{
  "episode": "tj01", "no": 1,
  "title": ["最强的智伯，", "为什么输了？"],
  "voice": "video/out/tj01_voice",
  "shots": [
    {
      "id": "1-1",
      "from": {"line": 0, "dt": -0.3},
      "to": {"line": 1, "word": "给"},
      "size": "wide",
      "bg": [{"img": "sets/jin_land/sky.png", "depth": 0.1, "pos": [0, 0], "w": 1080}],
      "actors": [{"id": "sgm", "img": "chars/sgm_finger.png", "pos": [235, 1585], "h": 520, "flip": false,
                  "enter": "pop", "acts": [{"at": {"line": 0}, "do": "bounce"}, {"at": {"line": 1}, "swap": "chars/sgm_thumb.png"}]}],
      "camera": [{"move": "push", "amount": 0.07}],
      "fx": [{"type": "sticker", "name": "question", "pos": [800, 520], "at": {"line": 1, "word": "给"}}],
      "sfx": [{"name": "pop", "at": {"line": 0}}],
      "grade": "normal",
      "transition": "cut"
    }
  ],
  "rituals": [{"type": "kaoni", "at": {"line": 1}, "options": ["给", "不给"]},
              {"type": "card", "person": "zb", "at": {"line": 60}}]
}
```
- **时间一律锚在配音时间线上**：`{"line": 第几句, "word": "这句里的字", "dt": 偏移秒}`，不写死秒数。改了台词、重新配音，镜头会跟着走。
- 每个字的时间：Qwen3-TTS 不给字级时间，合成器按这一句的字数比例估算（锚到某个字时误差约 0.1–0.2 秒，够用）。
- 字幕、说话人标签、顶部标题条、水印由合成器按时间线自动加，分镜表里不写。
- `img` 路径相对于 `video/assets/`。朝向按 REGISTRY.md 登记的原图朝向算，`flip` 只在要反过来的时候写。

## 四、施工阶段、agent 和验收
| 阶段 | 做什么 | 谁做 | 验收 |
|---|---|---|---|
| **A 合成器核心** | `render.py`：读分镜表，解析锚点；背景分层、人物、换表情；镜头运动（推、拉、摇、移、冲击推、震屏、甩镜、呼吸漂移）；视差；字幕、说话人标签、标题条、水印；混音（配音、音效、背景音乐，说话时自动压低音乐，整集 −16 LUFS）；缓存和并行；出片时自动检查（闪烁、静止、响度、人声） | `ep-builder`（Sonnet 5.5 xhigh） | builder 自己跑测试：① 同样输入渲两次，帧的哈希一致；② 字幕出现的时间和时间线差不超过 1 帧；③ 用分镜表重做 17 秒小样，效果不差于原型；④ 速度：本机预览每 30 秒成片 ≤ 1 分钟，整集高清 ≤ 15 分钟。主会话看报告，不派 reviewer |
| **B 特效包** | 《节奏和特效》第五节的全部特效和转场（包括人名牌、游戏卡片、大字标题、解说台、颜色分段）；系列贴纸（**已画好** `video/assets/codex_series/stickers_v1.png`，拆图、去绿底后用）；固定音效（程序合成） | `ep-builder`（Sonnet 5.5 xhigh） | 出一条**特效样片合集**：每个特效 2–3 秒，画面上标名字。`ep-reviewer`（Sonnet 5.5 xhigh）查一轮：流畅、闪烁、儿童安全。然后发给 Chris，**这是施工阶段唯一请 Chris 看的东西** |
| **C 检查工具** | `script_check.py` 加两项警告：单句超过 15 字；旁白句数占比超过一半（对话为主）。`storyboard_check.py`：锚点、镜头长度、变化频率（每分钟 18–24 个镜头、长于 5 秒的不超过 8 个）、特效数量、闪烁次数、安全区、素材在不在、放大倍数（≤ 1.3）、朝向、人物第一次出场有没有人名牌。`board.py <集>`：阵容图、剪影图、场景总览，由 `board_tj01.py` 通用化而来。**Jev 工具**（照 `.claude/skills/jev-decisions/SKILL.md`）：`video/jev_pick.py <类别> <候选.json>`，类别有 analogy、quiz、catchphrase、title、cover_text、classify，打分加正反两个顺序的两两比较，自动混进一个对照项，输出排名；`video/motion/storyboard_jev.py`，逐镜问主体对不对、看不看得懂、吓不吓人、梗对不对，阈值不过就退出码 1 | `ep-builder`（Sonnet 5.5 xhigh） | 故意写坏的分镜表（`tests/bad_*.json`，每种错一个）都要报错；正确的要通过。Jev 工具：对照项都排最后；故意写成「主体不对」「吓人」的镜头都被标出来；没有 key 时立刻报错。builder 自己验 |
| **D 试做** | tj01 第一场（约 30 秒）走完第 4–7 步 | `ep-director` 写分镜表 → `ep-builder` 补素材、渲染 → `ep-reviewer` 查成片 | Chris 看第一场样片。通过了再做整集 |

顺序：先做 A；B 和 C 可以同时做（两个 builder，各管各的目录）；最后做 D。

**省钱的规矩**：
- builder 只读本文件和原型，报告写短；
- 除了 B 的特效合集和 D 的样片，不派 reviewer；
- 一项做完主会话就 commit，不攒。

## 五、以后每集怎么用
第 1–9 步见 `docs/自动化工作流-每集生成.md`。引擎要加新特效，走同样的流程：写进 `fx/`，补一段特效样片，写进《节奏和特效》的特效表。
