# 儿童历史动画：怎么把故事讲好（第 1 集「徙木立信」的讨论和决策）

> 2026-09-27。Chris 看完第 3 版样片的评价：画面「好」，讲故事「差」。原话：「太流水账了，只是把故事笼统讲了一次，毫无寓意意义，也没有让人明白为什么。」
> 这一轮只讨论、只做决策，不改视频。参与的有三方：
> - **Claude**：写剧本，读调研和史料
> - **Jev**：按写明的标准给剧本打分、逐句找划走点、两两比较
> - **两份调研**：
>   - 动画大公司和讲故事高手的原理
>   - 《资治通鉴》原文核对

## 1. 上一版为什么「流水账」

Jev 给样片打的分（0–4 分；「办法妙在哪」是 0–1 的概率）：

| 维度 | 样片得分 | 说明 |
|---|---|---|
| 开头钩子 | 0.55 | 用「两千多年前，秦国有个大官」开头，是背景介绍，不是钩子 |
| 讲清为什么 | 1.80 | 只交代了「他要推行新法」，没讲清为什么非得先让人相信 |
| 办法妙在哪 | 0.29 | 完全没讲为什么偏偏是搬木头、为什么给这么多 |
| 失败的后果 | 0.89 | 看不出做不成会怎样，观众不会着急 |
| 困难升级 | 0.56 | 只有一关，一下就过了 |
| 联系孩子生活 | 0.20 | 和孩子的生活毫无关系 |
| 两两比较 | 讲懂 0.07，转发 0.05 | 10 版里垫底 |

另外两个问题，是做这一轮时才发现的：

- **语速太快。** 15 秒塞了 7 句，最快的一句 2.6 秒念 22 个字（每秒 8 个字）。孩子能跟上的语速大约是每秒 4 个字。
- **有一处史实错误。** 「老百姓都觉得官府说话不算数」没有史料依据。原文只写：
  - 商鞅担心百姓不信（「恐民之不信」）；
  - 百姓觉得这件事奇怪（「民怪之」）。

所以不只是时长太短。上一版只讲了「发生了什么」，没讲「为什么」和「后来怎样」。

## 2. 高手们怎么讲（调研摘要）

| 来源 | 原理 | 用在这一集 |
|---|---|---|
| Pixar（Emma Coats 的 22 条） | #16 讲清赌注，让胜算更小；#7 先定结局再写中间；#13 配角要有自己的观点 | 前 20 秒讲清「不信 = 新法作废 = 秦国永远又穷又弱」；围观者分成怀疑的爹、馋钱的孩子、敢试的小伙 |
| Story Spine（Kenn Adams） | 从前 → 每天 → 有一天 → 所以 → 因为 → 直到 → **从此以后** | 上一版缺了最后的「从此以后」 |
| Andrew Stanton（TED 演讲） | 先让观众在乎；「2+2 原则」：别直接给答案 4，给观众 2+2 让他自己算；戏剧就是期待里掺着不确定 | 小伙伸手抬木杆前停一拍：「会不会是陷阱？」 |
| 帕克和斯通（《南方公园》） | 情节之间只能用「但是」或「所以」连，不能用「然后」 | 想变强，**但是**没人信 → **所以**立木 → **但是**没人敢搬 → **所以**加到五十金 → **但是**太子犯法 → **所以**罚老师 |
| Bluey（Joe Brumm） | 同一个画面，孩子和家长各笑各的；寓意靠角色的变化体现，不说教 | 「妈妈的卷子」：孩子觉得被说中了，家长也被轻轻点名 |
| TED-Ed、Kurzgesagt | 全片挂在一个问题上：开头问，中间给线索，结尾回答 | 「为什么偏偏搬木头？」由小豆子问出来，再让观众猜 |
| 如果历史是一群喵、半小时漫画 | 萌角色负责好笑，史料负责可信；用现代类比；「能画画绝不写字」 | 信用值、关卡、BOSS 这些游戏说法 |
| 短视频留存 | 3 秒内亮出核心，6 秒内放出钩子；开放式问题；标题许下的承诺要兑现 | 用 Jev 逐句检测最长的平淡段 |

### 史料核对：必须避开的坑

核对依据是维基文库的《资治通鉴》卷二（四库全书本），以及《史记》卷五、卷六、卷六十八。

1. **没有任何记载说秦国官府以前骗过老百姓。** 不能编造「官府以前说话不算数」。
2. **按《通鉴》的年代，太子当时最多是个婴儿。** 不能演成会顶嘴的少年，太子本人最好不出镜。
3. **秦国那时还没有铸钱**，二十多年后才开始铸。不能画圆形方孔钱，要画成金块。
4. **木头是竖在集市南门的一根木杆，三丈高（约 7 米）。** 从集市南门搬到集市北门。都城是栎阳，不是咸阳。
5. **当时秦君称「公」，不称「王」。** 「商鞅」这个称呼是十几年后受封商地才有的，当时叫卫鞅。片子里沿用大家熟悉的「商鞅」，笔记正文里注明。
6. **「作法自毙」的旅店故事只在《史记》里**，《资治通鉴》里没有。
7. **刑罚：** 太子的两位老师，一位受刑，一位脸上被刺字（黥）。给孩子只说「罚了两位老师」，不画受刑过程。

## 3. Jev 是怎么参与决策的

### 评分标准
标准在 `rubrics/story_v1.json`，评测脚本是 `video/story.py`。

**整部剧本打 12 个分**，都是 0–4 分，每一档都写成具体情形。例子故意用别的故事（曹冲称象），免得标准偏向某一版剧本。12 项是：
- 开头钩子
- 讲清为什么
- 办法妙在哪
- 失败的后果
- 困难升级
- 留存
- 寓意
- 联系孩子生活
- 大人那一层
- 孩子的笑点
- 游戏机制
- 清晰度

**两道闸门：**
- 史实：对照原文和上面那张「坑」的清单
- 儿童不宜

**逐句检测：** 每一句都问「这一句有没有给观众继续看的新理由」，再用代码算出最长的平淡段有几秒。

**两两比较：** 每两版放在一起问三个问题。每对都正着问一次、反着问一次，抵消 Jev 偏爱某个位置的倾向。
- 孩子更可能看完哪条？
- 看完后孩子更能说清道理的是哪条？
- 家长更想转发哪条？

### 先检验标准本身靠不靠谱
方法：拿一版剧本，每次只删掉一样东西，看对应那一项会不会掉分。

| 删掉什么 | 应该掉的那一项 | 结果 |
|---|---|---|
| 生活开头（换成年代开头） | 开头钩子 | 3.69 → 0.93 ✓ |
| 太子那一段 | 困难升级 | 3.35 → 1.29 ✓ |
| 结尾的道理和回到生活 | 寓意、联系孩子生活 | 3.83 → 3.44；3.95 → 3.24 ✓ |
| 讲原因的句子 | 失败的后果 | 2.90 → 2.10 ✓ |
| 「妙在哪」那一句 | 办法妙在哪 | 0.98 → 0.65 ✓ |

**不靠谱、所以改掉的两处：**
- **「因果推进」这一项删了。** 每版都接近满分，连 Chris 评为「差」的样片也拿了 3.92，说明它量不出「流水账」。
- **「办法妙在哪」改严了。** 第一版每版都接近「是」。改成必须有台词或画面**明确点出**原因，才分得开。

后面又比了两轮，每轮只和上一轮的赢家比。胜率是在同一轮的几版之间算出来的，所以不能和上表 10 版的胜率直接对比。

**第一轮：H5 对 H、H2。** H5 = H2 + 讲原因改成「你猜猜？」加解锁徽章。
- 均分 3.35，最长平淡段只有 6.9 秒；
- 胜率：看完 0.78，讲懂 0.73，转发 0.79。

**中间做了一次史料复核。** 请史料核对再逐句审 H5，按意见改了 5 处：
- 「最怕老百姓也这么想」会让人以为官府以前骗过人 → 改成「最怕老百姓不信他的话」；
- 「写这个故事的是司马光」不准确，最早是司马迁写在《史记》里的 → 改成「被写进了一本大书，写书的人是司马光」；
- 「信用是最大的宝贝」→ 改成「说话算数，是管事的人最大的宝贝」，贴近原文「人君之大宝」，还顺带把家里管事的妈妈扣了回来；
- 钱袋（当时还没有钱币）改成布包袱，而且是「绕过去不拿」，这才是「道不拾遗」的意思；
- 法槌（近代西方法庭的道具）改成「把竹简往案上一拍」。

改完后司马光那句变长了，最长平淡段回到 10.6 秒。

**第二轮：H6 对 H5。** H6 = 司马光先卖关子「写书的人，你肯定认识——」，再跳出来说「就是小时候砸缸的我！」；「新法公布」改由商鞅自己说。
- 均分 3.33，最长平淡段 6.6 秒；
- 胜率：看完 0.69，讲懂 0.53，转发 0.67。
- **H6 就是推荐剧本。**

**从结果里学到的规律**（以后每集都用）：

1. **生活开头最能留人。**
   - 「妈妈的卷子」开头：钩子 3.7，联系孩子生活 3.96。
   - 换成司马光主持或「你搬不搬」开头，联系孩子生活只有 1.2–2.0，看完率也更低。
2. **讲道理的句子就是划走点。**
   - 旁白直接讲「事情小、人人看见、当场给钱」，这一句逐句检测只有 0.32，是全片最平淡的一句。
   - 改成「你猜猜？」停一拍，再让三个徽章「叮」地解锁，最长平淡段从 11 秒降到 7 秒，讲懂和看完都提高了。
3. **结尾那句道理本身留不住人，要在它后面接一个笑点。**
   - 大多数版本的最后一句道理都是平淡的（0.19–0.45）。
   - 只有接上「妈妈，那张卷子……」的版本，结尾立住了（0.84）。
4. **各讲法的长处可以互补。**
   - 悬念倒叙最能讲懂，但孩子最不容易看完；
   - 孩子视角最能留人，但讲不清道理；
   - 合成之后两头都拿到了。
5. **小品式的笑点不能代替故事。**
   - 古人说现代话这一版，孩子笑点最多（3.63），但讲懂只有 0.12，转发只有 0.13。

**这一版对照高手原理，分别做到了什么：**
- **赌注**（第 20 秒）：大家不信，新法就作废，秦国永远又穷又弱。
- **但是/所以**：因果一路推到底，没有「然后」。
- **期待里掺着不确定**（第 53 秒左右）：小伙伸手前停一拍。
- **2+2**（第 64 秒左右）：先问「你猜猜？」，再揭晓答案。
- **困难升级**：三关一关比一关难。
  - 第一关：奖励算不算数；
  - 第二关：惩罚连大人物也算不算数；
  - 第三关：能不能坚持十年。
- **寓意靠角色变化说出来**：怀疑的爹最后说「我信了」。
- **作者本人点题**：司马光自己跳出来说出他在书里的评语「信者，人君之大寶也」（说话算数，是管事的人最大的宝贝），这也是他本人的观点，不是我们在说教。
- **双层笑点**：孩子笑小豆子，家长笑妈妈藏卷子。

**留给家长的那一层放在笔记正文里，不塞进视频：**
- **故事最早出自司马迁的《史记》，是砸缸的司马光把它收进了《资治通鉴》。** 他夸的是「说话算数」，不是商鞅。他在书里说，连「刻薄」的商鞅都不敢丢掉信用。
- **商鞅的结局。** 新法很严，商鞅后来也被处死了。
- **这一招其实有人用过。** 更早的吴起在魏国就立过木桩、悬过赏（见《吕氏春秋》和《韩非子》）。
- **故事还有另一面。** 十年后，连夸新法好的人也被赶到边疆，「从此没人敢议论法令」。大家是信了，还是怕了？

## 6. 请 Chris 拍板的事

1. **顶部标题**。两版正文相同，只换标题：
   - 「大人说话不算数 / 你还会听吗？」：孩子看完率和家长转发率更高（直接对比：看完 0.57，转发 0.75）；
   - 「搬根木头 / 凭什么给五十金？」：孩子看完后更能说清道理（0.60）。

   **建议：** 视频顶部用生活问题；小红书笔记标题用「搬根木头凭什么给五十金？」，把两个钩子都用上。
2. **系列固定格式**。每集开头是一个孩子生活里的问题；中间是信用值或其他数值做成的三关闯关；结尾是「司马光说」加上回到生活的一个笑点。
   - 小豆子做成跨集的固定角色（每集都在历史现场围观的小孩）。
   - Jev 的结果是：司马光适合在结尾点题，不适合当开场主持。开场主持时，联系孩子生活只有 1.2。
3. **时长**。故事讲完整需要约 2 分钟，已经到你定的 1–2 分钟的上限。
4. **下集钩子要不要加**（5 秒）。「被罚的太子老师公子虔，八年没出家门。他在等一个机会……」
   - 这句有《通鉴》依据：赵良说过「公子虔杜门不出已八年矣」；后来正是「公子虔之徒告商君欲反」。
   - 第 2 集要讲到商鞅被处死。给孩子只说「最后被处死了」，车裂的细节只写进家长说明。
