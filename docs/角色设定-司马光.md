# 角色设定：司马光（系列讲解人）· 2026-09-27 草案

## 为什么是他
系列按《资治通鉴》的顺序讲，正式第 1 集是三家分晋。能每集都合理出现的只有作者本人：书里很多故事后面都有一段「臣光曰」，是司马光亲自点评。三家分晋讲礼和名分、讲智伯「才胜德」，徙木立信讲「夫信者，人君之大宝也」。所以「每集结尾司马光出来点题」有原文依据。

## 素材
- 定稿素材表：`video/assets/codex_ep01/sgm_v2.png`，5 个姿势，绿幕，提示词在 `sgm_v2.txt`
  1. 捧书笑着看观众（开场）
  2. 举起食指讲道理（点题「臣光曰」）
  3. 捋胡子、皱眉（不赞同）
  4. 警枕滚落，惊醒
  5. 握毛笔、竖大拇指（夸奖）

## 每个设计点的依据（对应 `docs/research/儿童动画角色100-画风拆解.md`）
| 设计 | 调研里的规律 | 史实依据 |
|---|---|---|
| 展脚幞头的两根长帽翅，涂黑后是「T」字 | 剪影能认出来（米奇三个圆、哪吒丸子头）。剪影对比里他是全部角色中最好认的 | 宋代官员的标准官帽 |
| 主色紫色 | 一个主色 + 一个标志物；和小豆子的橙红撞色，也避开商鞅的靛青 | 宋代高官穿紫（元丰改制后四品以上服紫）；他后来做到宰相 |
| 方正的身体 + 圆脸 | 形状就是性格：方 = 倔、正直，圆 = 亲切 | 苏轼给他起过外号「司马牛」，说他倔 |
| 头身比约 2.5，和其他角色一致 | 6–12 岁的观众适合 2–3 头身的 Q 版 | — |
| 粗灰眉，表情主要靠眉毛 | 眼睛简单，靠眉毛表情（小新、胖红） | — |
| 胡子短，不遮嘴 | 我们的口型动画需要看到嘴 | 画像里他有胡子，这里做了 Q 版简化 |
| 警枕：打瞌睡时圆木枕头滚掉就惊醒 | 性格反差（大学者也会犯困）+ 能做成表情包 | 史料记载他「以圆木为警枕」，睡着了枕头一转就醒，起来接着读书 |
| 5 个姿势 | 每个主角 5 个招牌表情，可以做封面和贴纸 | — |

## 已知问题（做纸偶部件时再改）
- 姿势 2–5 的领口画成了交领。宋代官服应该是圆领，只有姿势 1 接近圆领。拆部件时统一改成圆领。
- 姿势 3「不赞同」看起来有点像发愁，可以在纸偶里靠压低眉毛来加强。
- 还没有做纸偶部件（侧面 + 45° 各一套）。Codex 本地和云端现在都能用。

## 可选的第二套造型
史料记载他在洛阳独乐园写书时，按《礼记》自制深衣、幅巾，在园子里就穿这一身，出门上朝才换官服。以后讲「写书的司马光」时可以用这套造型，平时统一用官服，保证剪影一致。
