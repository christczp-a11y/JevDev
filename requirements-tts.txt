# Qwen3-TTS 配音环境（独立于主环境 .venv；只在有显卡的本地电脑上装）。2026-09-29，GTX 1660 Ti 6GB（Turing：没有 bf16，用 fp16；不装 flash-attn）实测过。
# 建环境（需要 Python 3.12；Windows 上可以 pip install uv 后 uv python install 3.12，再用那个 python -m venv）：
#   <python3.12> -m venv .venv-tts
#   .venv-tts/Scripts/python -m pip install torch==2.9.1 torchaudio==2.9.1 --index-url https://download.pytorch.org/whl/cu126
#   .venv-tts/Scripts/python -m pip install -r requirements-tts.txt
# 模型下载到默认的 HuggingFace 缓存（不进仓库），第一次运行 voice.py 会自动下载，共约 8.5 GB：
#   Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign（设计参考音）、Qwen/Qwen3-TTS-12Hz-1.7B-Base（克隆念句子）
# 显存：两个模型各占约 4.2 GiB，不能同时放进 6 GB，worker 设计完先释放再加载克隆模型；峰值约 4.9 GiB。
